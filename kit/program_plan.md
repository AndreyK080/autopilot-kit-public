## Программа

- Цель: бот в Telegram, который принимает расходы сообщением и раз в неделю присылает сводку по категориям
- Результат программы: бот работает на сервере владельца, данные хранятся в SQLite, есть резервная копия
- Режим прогонов: full
- Источники: `docs/idea.md`, `docs/architecture.md`

### M1. Приём расходов

- Результат: код
- Цель: бот принимает сообщение «кофе 250» и сохраняет расход с категорией и датой
- Входит: разбор сообщения «описание сумма», категории из Q01, хранение в SQLite, ответ-подтверждение, тесты
- Не входит: сводки, редактирование записей, развёртывание на сервере
- Критерии сдачи:
  - сообщение «кофе 250» сохраняет запись с суммой 250 и категорией «еда», бот отвечает подтверждением
  - сообщение без суммы — понятная ошибка, запись не создаётся
  - `python -m pytest -q` — зелёный
- Зависит от: —
- Передаёт дальше: таблица `expenses` (дата, сумма, категория, описание) и функция `add_expense`
- Размер: T1
- Источники: `docs/idea.md` §1–2, `docs/architecture.md` §Хранение

### M2. Недельная сводка

- Результат: код
- Цель: раз в неделю бот присылает сумму расходов по категориям за прошлую неделю
- Входит: расчёт сводки по таблице `expenses`, отправка по расписанию из Q02, команда /summary
- Не входит: графики, сводка за месяц
- Критерии сдачи:
  - команда /summary присылает суммы по категориям за последние 7 дней
  - сводка по расписанию приходит в день и час из Q02 (проверено тестом с подменой времени)
  - `python -m pytest -q` — зелёный
- Зависит от: M1
- Передаёт дальше: функция `weekly_summary`
- Размер: T1
- Источники: `docs/idea.md` §3

### M3. Развёртывание и резервная копия

- Результат: код
- Цель: бот работает на сервере владельца как служба и раз в сутки сохраняет копию базы
- Входит: unit-файл systemd, скрипт резервной копии по Q03, инструкция запуска в README
- Не входит: мониторинг, CI
- Критерии сдачи:
  - README описывает установку в 5 команд, проверено на чистой папке
  - скрипт копии создаёт файл с датой и удаляет копии старше срока из Q03
- Зависит от: M1, M2
- Передаёт дальше: —
- Размер: T0
- Источники: `docs/architecture.md` §Развёртывание

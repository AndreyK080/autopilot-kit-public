# Правила проекта (небольшой веб-проект)

## Запуск
- Тесты: `python -m pytest -q` из корня проекта. Если есть `package.json` с тестами — добавь `npm test` в `.autopilot-kit/project.toml`.
- Гейт качества: `python "<~>/.autopilot-kit/bin/gate.py"` — запускает команды из `.autopilot-kit/project.toml`.

## Стиль
- Простота важнее набора технологий: без лишних зависимостей и сборщиков, пока без них можно обойтись.
- Тексты интерфейса и ошибки — на языке пользователя; секреты и ключи не попадают в код и в репозиторий (`.env` не читать и не коммитить).
- Каждое поведение покрыто тестом; тесты не требуют сети и запущенного сервера, если это можно обойти.

## Готовность
- Не объявляй задачу готовой, пока гейт не пройден. Перед словом «готово» выполни гейт и покажи его вывод.
- Красные тесты — это не «почти готово», а незавершённая работа.

## Роли Autopilot
- Субагентов Autopilot запускай по навыку `autopilot-roles`: типы агентов `autopilot-executor`,
  `autopilot-reviewer-spec`, `autopilot-reviewer-craft`, `autopilot-final-reviewer`.
- Не меняй модель и усилие субагента вручную: они берутся из профиля `~/.autopilot-kit/profile.toml`.
